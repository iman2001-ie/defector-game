### Cross-story (diff-scope review: adversarial, edge-case and verification-gap lenses)

**F1 (medium, fix). A dead attempt can still clear the level.**
- **Source:** `wave_director.gd:419-447` (`_try_clear` / `_finish_level`). The only listener for `player_died` / `level_failed` is `retry_prompt.gd:71`. The wave director and `level_clear_banner.gd` never react to death.
- **Scenario A:** The ship dies during the final wave gap. The 1.5 s death beat (`retry_prompt.gd:125-135`) is unpaused until it ends, so `level_cleared` can still fire, and LEVEL CLEAR shows under HULL DESTROYED.
- **Scenario B:** The ship dies after LEVEL CLEAR (bullets and asteroids are still live). The retry prompt then shows over the banner.
- **Also:** in-flight micro-missiles and missiles keep scoring kills after death (`player.gd:193-208` only stops new launches). That progress counts toward the clear.
- **Boundary:** 3-2 × 3-5 × the Epic 2 wave director.
- **Why it matters:** Epic 4.2 attaches unlock and save to `level_cleared`, so a dead attempt could unlock the next level.
- **Test gap:** no test combines a death with a clear. Story specs 3-2 and 3-5 list this as a residual risk but did not defer it.

**F2 (low, defer). Retry lifts the death pause one frame early.**
- **Source:** `scene_router.gd:86-90` calls `PauseArbiter.clear()` before the deferred scene change.
- **Effect:** `resumed` fires and the dead Player warps the cursor (`player.gd:440-442`). The old scene can run unpaused for up to one frame.
- **Status:** code path read, timing not observed.

**F3 (low, defer). F5 leaves stale state after death.**
- **Source:** `debug_tools.gd:131-151, 214-226`. The F4 key works during the death pause, and the F5 reset does not clear `GameState.energy` or `is_retry`.
- **Effect:** debug only, but it pollutes playtest repro steps.

## Action items

All of these are proposals. Code fixes go to the normal dev loop, and spec or design changes need the developer to apply them.

1. **Make a level end exactly once: cleared or failed.** Once `level_failed` fires, the wave director must not emit `level_cleared` and should stop counting kills toward the clear. A death after `level_cleared` must not open the retry prompt (or the policy must be decided). Add a test that combines a death with a clear (F1). Do this before Epic 4.2 attaches save and unlock to `level_cleared`. Owner: Dev loop. Type: remediation.
2. **Split `player.gd`.**
   - Extract the hearts/i-frames state into the planned `HealthComponent` (or record a decision that replaces it), and extract the shield into a `PlayerShield` component.
   - Fold `try_shield`/`try_barrage` into one spend gate (A1, A3).
   - Do this before Epic 4/6 add more Player rules.
   - Owner: Dev loop, with the Architect for the HealthComponent decision. Type: remediation plus spec reconciliation.
3. **Add a shared player test fixture** (`tests/fixtures/player_test_base.gd` plus a hazard factory) and move the five player test files onto it (A2). Owner: Dev loop. Type: remediation.
4. **Record the Epic 3 design deviations in the decision log:**
   - asteroids survive contact (S1)
   - the new tuning values and the `ui` tuning section (S3)
   - clarify the retry-headline anchor in `DESIGN.md:100` (S2)

   Owner: Developer. Type: spec reconciliation.
5. **Playtest the Epic 3 manual checks** listed in specs 3-1 to 3-5. Owner: Developer (operator).
6. **Close the loop on decisions that were "closed" but never applied:**
   - set `epic-1`, `epic-2` and `epic-3` to `done` in `sprint-status.yaml` (DW-43, P3)
   - raise `max_tokens_per_story` in the loop policy, sized to the single-system stories that overran here (DW-45, P1)
   - add the per-script or randomised-order verify command (DW-44, P2)

   Then confirm each in the next run's journal. Owner: Developer (operator) / loop config. Type: process.
7. **Process lesson: verify the effect before closing a sweep item "by human decision".** Before closing such an item, record the commit or config change that applies it, or leave it `in-progress`. Three such closures (DW-43, DW-44, DW-45) did not take effect for the Epic 3 run. Owner: Planning (SM). Type: process.
8. **Tidy the debug and retry edges:**
   - `SceneRouter` should clear pauses at the point of the scene swap, not before it (F2).
   - F5 should reset `GameState` energy and retry state (F3).
   - Add a `Groups` const class (A5).

   Owner: Dev loop. Type: remediation (low).
